# Code for the Papers

This repository collects the code and data accompanying my papers. Each paper lives in its own
directory with an independent README, environment file and entry scripts, so a single directory
can be cloned and run on its own.

## Papers

| # | Paper | Code | Status |
|---|---|---|---|
| 1 | **An SVIR epidemic model with an evolutionary game of prevention compliance under vaccination**<br>Guoqing Hu, Zunhai Gao and Yakui Xue | [`paper-1/`](paper-1/) | Available |
| 2 | **A threshold-free warning week for dengue take-off: seasonally forced transmission and surveillance in Guangzhou, China (2025)** | [`paper-2/`](paper-2/) | Code coming soon |

## Layout

```
.
├── paper-1/                 # SVIR-RE: epidemic model coupled to an evolutionary game
│   ├── README.md            # file-by-file guide and figure-to-data map
│   ├── requirements.txt     # Python dependencies
│   ├── src/                 # 3 Julia + 8 Python scripts
│   ├── data/                # baseline simulation data
│   └── results/             # current verification and efficacy results
├── paper-2/                 # dengue warning week (code to be added)
├── CITATION.cff
└── LICENSE
```

## Conventions

- Every paper directory is self-contained: its own README, its own dependencies, its own entry point.
- Figures are not committed. They are regenerated by the scripts in each paper directory.
- All code is released under the MIT license unless a paper directory states otherwise.

## Citing

If you use code from a paper directory, please cite the corresponding paper. Each
`paper-*/README.md` gives the citation of that paper; `CITATION.cff` describes the repository
as a whole.
