# Figures

`main/` holds the vector figures exactly as placed in the manuscript, in
manuscript order:

| File | Manuscript |
|---|---|
| `fig1_c4_warning_week.pdf` | Fig. 4 (onset weeks vs rho, both lags) |
| `fig2_fit_main.pdf` | Fig. 2 (calibration) |
| `fig3_est_prob.pdf` | Fig. 7 (local-detection probability) |
| `fig4_rho_profile.pdf` | Fig. 5 (reporting-ratio profile) |
| `fig5_risk_window.pdf` | Fig. 3 (seasonal R0 window) |
| `fig6_traits_robustness.pdf` | Fig. 6 (trait sensitivity) |

The file names are historical (they follow the experiment that first produced
them) and do **not** match the manuscript figure numbers. Fig. 1 of the
manuscript is a native-size TikZ schematic compiled inside the paper source and
has no standalone PDF here.

`source_data/` holds one directory per figure with the exact numbers behind
each panel, written by the figure scripts. `source_data/MAP.csv` maps panel
files to manuscript panels.
